# GharMB Real Estate Platform — Product Requirements Document

## Product Vision

GharMB is a modern real-estate platform designed to make property discovery, verification, listing, buying, renting and real-estate decision-making simpler and more trustworthy.

The marketing website should communicate this product vision before asking users to enter the application.

The website should answer four questions quickly:

1. What is GharMB?
2. Why should users trust it?
3. What can users do with it?
4. How can users get started?

---

# 1. Primary Website Goals

The website should:

- Build trust
- Explain GharMB
- Showcase the product ecosystem
- Drive users toward property discovery
- Encourage property owners to list
- Attract developers and agents
- Promote verified properties
- Promote useful real-estate tools
- Establish GharMB as a modern real-estate technology platform
- Generate organic traffic through the blog

# Section 02 — Hero

The hero should immediately communicate GharMB.

Suggested messaging direction:

"Find a place that feels like home."

Supporting copy:

"Discover verified properties, trusted developers and smarter real-estate tools — all in one place."

Primary CTA:

Explore Properties

Secondary CTA:

List Your Property

Hero visual:

Use a strong real-estate image.

Do not use a generic SaaS illustration.

The image should feel architectural, premium and Indian real-estate relevant.

Possible visual:

Luxury apartment / modern residential building / city property.

Overlay a small GharMB verification badge or property information panel.

Keep this subtle.

# 7. Conversion Strategy

Primary conversion paths:

Visitor
→ Explore Property

Owner
→ List Property

Developer
→ List Project

Reader
→ Read More / Explore Properties

The page should never feel like aggressive marketing.

Trust first.
Information second.
Conversion third.

---

# 8. Product Personality

GharMB should feel:

Trustworthy
Modern
Warm
Architectural
Human
Premium
Simple
Useful

Avoid:

Corporate banking feel
Generic startup feel
Overly luxurious gold/black real estate style
AI-generated aesthetic
Excessive animations
Excessive glassmorphism
Neon gradients
Dark futuristic UI

---

# 9. Success Criteria

A visitor should understand GharMB within the first 5–10 seconds.

The website should communicate:

Real estate
Trust
Verification
Discovery
Tools
Professional ecosystem

without requiring the visitor to read large paragraphs.
