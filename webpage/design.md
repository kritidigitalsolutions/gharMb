# GharMB — Design System & UI Direction

## Design Objective

Create a premium modern real-estate website for GharMB.

The visual identity must be derived from the supplied GharMB mobile application screenshots.

The app uses a warm orange/coral brand system.

The website must use the same brand DNA but should NOT simply copy the mobile application.

The website should feel like the mature web presence of the same product.

# 3. Color Usage Rule

Orange is an accent, NOT the entire website.

Do not make every section orange.

Use orange primarily for:

CTA
active state
links
badges
small highlights
icons
progress
micro-interactions

Approximately:

70% neutral
20% warm/soft surfaces
10% brand color

The page should remain visually calm.

---

# 4. Typography

Typography must feel editorial and premium.

Recommended primary font:

Inter

Alternative:

Manrope

Alternative for editorial headings:

DM Sans

Do not use futuristic fonts.

Do not use overly rounded startup fonts.

Do not use excessive font weights.

Suggested:

Body:
15–17px

Small:
12–14px

H1 desktop:
56–72px

H1 mobile:
38–46px

H2:
40–52px

H3:
24–32px

Use tight but comfortable heading line-height.

Body line-height:
1.5–1.7

---

# 5. Iconography

Preferred:

Lucide React
Remix Icon
IconScout

Use one primary icon system consistently.

Icons should be:

- thin
- simple
- geometric
- 1.5–2px stroke
- visually quiet

Avoid:

3D icons
emoji icons
random icon styles
multi-color illustrations
huge decorative icons

---

# 6. Layout System

Desktop max width:

1200–1280px

Large desktop:

1320px maximum where required.

Horizontal padding:

Desktop:
32–48px

Tablet:
24–32px

Mobile:
16–20px

Use generous whitespace.

Do not fill every empty area.

---

# 7. Grid

Use a 12-column desktop grid.

Typical:

Hero:
5 / 7

Editorial section:
5 / 7

Property cards:
3-column

Blog:
3-column

Feature:
4 / 8

Do not force everything into 3 equal cards.

Use asymmetric layouts.

---

# 8. Border Radius

Use moderate radius.

Primary cards:
16–20px

Buttons:
10–12px

Input:
10–12px

Large image containers:
20–28px

Avoid:

40–60px excessive pill-shaped UI.

Pills are only for:

filters
categories
statuses
tags

---

# 9. Shadows

Use shadows very sparingly.

Preferred:

0 4px 20px rgba(0,0,0,0.06)

or subtle border-first cards.

Do NOT use:

large glowing shadows
colored shadows
floating neumorphism
heavy elevation

The design should rely on:

spacing
typography
borders
imagery

rather than shadows.

---

# 10. Navbar

Desktop navbar:

Height:
72–80px

Logo left.

Navigation center.

CTA right.

Use a subtle border-bottom or transparent state.

On scroll:

white background
subtle shadow/border
slightly compact height

Do not create a giant navbar.

---

# 11. Hero Design

The hero should be visually memorable.

Recommended composition:

Left:
Large headline
supporting copy
CTA buttons
small trust indicators

Right:
Large architectural property image

Use image cropping carefully.

Add one or two subtle property information overlays.

Example:

"Verified Property"

"3 BHK · 1480 sq ft"

"₹85 Lakh"

These overlays should feel like real product information, not decorative floating cards.

Avoid 5–10 floating cards.

---

# 12. Hero Background

Use mostly white/warm white.

Possible:

Very subtle coral gradient wash.

Gradient must be almost invisible.

No huge colorful gradient background.

---

icon + title + paragraph

icon + title + paragraph

# 22. Animation

Use subtle motion only.

Allowed:

fade-up
image scale 1.02
button hover
card image zoom
drawer slide
navbar transition
counter animation

Duration:

150–400ms

Use ease-out.

Avoid:

parallax everywhere
scroll-jacking
bouncing elements
continuous floating animations
huge entrance animations

---

# 23. Responsive Behavior

Mobile design is NOT a compressed desktop.

At mobile:

Navbar → hamburger + logo + CTA/icon

Hero:
stacked

Property cards:
single column

Blog:
single column

Large grids:
horizontal scroll only where useful

Stats:
2-column or horizontal scroll

CTA:
full width where appropriate

Spacing must reduce intelligently.

---

# 24. AI-Generated Design Prevention Rules

IMPORTANT.

Do not use common AI-generated web patterns such as:

- giant gradient blob
- excessive glass cards
- random floating UI
- 8 identical cards
- huge centered headline with generic copy
- purple-blue gradient
- excessive rounded corners
- fake 3D illustrations
- random abstract shapes
- excessive badge usage
- every section centered
- excessive shadows
- generic "Empowering the Future" copy
- generic SaaS wording

Every section must have a clear real-estate purpose.

---

# 25. Premium Rule

Premium does NOT mean adding more effects.

Premium should come from:

Typography
Whitespace
Photography
Grid
Alignment
Consistency
Content hierarchy
Micro-interactions

---

# 26. Design Quality Checklist

Before finalizing:

- Does it look like GharMB?
- Does it visually connect to the mobile app?
- Is orange controlled?
- Is typography premium?
- Are images strong?
- Does it feel like real estate?
- Does it avoid SaaS-template aesthetics?
- Does mobile feel intentionally designed?
- Is the blog editorial?
- Is the blog detail page professional?
- Does the drawer feel native?
- Are animations subtle?
- Are sections visually varied?
